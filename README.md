# ⏱️ Tempo Personal Dashboard

A clean and intuitive personal productivity dashboard. Built with a local first approach, all your data stays safely stored in your browser without requiring registration or setup.

Tempo helps you maintain focus, manage daily tasks, and keep your essential links accessible in one place.

## ✨ Key Features

* **Focus Timer (Pomodoro)**: 25 minute work intervals and break presets with audio chime notifications and a visual progress ring.
* **Task Manager**: Add daily tasks, filter by active or completed status, and sort queue order.
* **Quick Links**: Bookmark your frequently visited websites for quick access.
* **Live Clock & Greeting**: Real time clock with dynamic greetings based on the time of day and focus session telemetry.
* **Light & Dark Theme**: Toggle between light and dark modes tailored for comfortable viewing in any lighting environment.
* **Keyboard Shortcuts**:
  * `Space` : Start or pause timer
  * `Alt` + `N` : Focus new task input
  * `Alt` + `T` : Toggle theme
  * `Esc` : Cancel or close modal

## 🚀 Quick Start

Tempo is a pure static web application and requires no `npm` dependencies or build process.

1. Download or clone this repository.
2. Open `index.html` directly in your browser.
3. Your dashboard is ready to use.
